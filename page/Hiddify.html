怎样把应用安装到设备上？

Windows 10（版本 1809）/ 11，64 位

  1. 点击 Windows 下载按钮，等待 .exe 文件下载完成。
  2. 打开浏览器下载记录，或进入“下载”文件夹，双击安装文件。
  3. 如出现 Windows 安全提示，先确认文件来自 Hiddify 官方 GitHub 发布页；确认后再按提示选择“更多信息”→“仍要运行”。
  4. 按安装向导继续，通常保持默认安装位置即可；完成后点击 Finish（完成）。

macOS 10.15 或更新版本（Intel / Apple 芯片）

  1. 下载 .dmg 文件，在“下载”文件夹中双击打开。
  2. 将 Hiddify 图标拖入 Applications（应用程序）文件夹，等待复制完成。
  3. 从“应用程序”文件夹打开 Hiddify。若 macOS 阻止打开，请先核对下载来源，再严格按Hiddify 官方 macOS 安装说明处理；不要使用第三方修复工具。

Android 7.0 或更新版本

  1. 优先点击 Google Play，进入应用页后点击“安装”，完成后点击“打开”。
  2. 如果无法使用 Google Play，可下载 APK；下载完成后从通知栏或“文件 / 下载”中点开。
  3. 若系统提示禁止安装未知应用，只为当前浏览器或文件管理器临时开启“允许来自此来源”，返回安装界面点击“安装”；安装完成后建议关闭该权限。

iPhone / iPad（iOS 15 或更新版本）

  1. 点击 App Store，点“获取”，使用 Face ID、Touch ID 或密码确认。
  2. 安装完成后点击“打开”。如果商店搜索不到，可能是当前 Apple ID 地区暂未提供该应用。
我有订阅链接 / 配置二维码

方法 A：通过服务商提供的用户页面导入（优先）

  1. 打开服务商发给你的个人用户页面。
  2. 点击页面上的“连接 / 在 Hiddify 中打开”按钮。
  3. 浏览器询问是否打开 Hiddify 时，选择打开；回到应用确认配置已添加。

方法 B：复制链接后手动导入

  1. 复制完整的订阅链接。订阅链接通常以 https:// 开头；单个节点配置也可能以 vless://、vmess:// 等开头。
  2. 打开 Hiddify 首页，点击顶部 ＋。
  3. 选择 Clipboard（剪贴板）导入；或选择 Manually（手动），粘贴链接并点击 Add（添加）。
  4. 如果拿到的是二维码，选择 QR code / Scan QR 扫描；如果拿到配置文件，选择 File 导入。
成功标志：首页出现一个 Profile（配置 / 订阅）卡片。提示 Invalid URL 或 Failed to add profile 时，检查链接是否复制完整、是否过期；不要把链接发给陌生人排查。
我没有订阅链接，能先试用吗？

可以查看 Hiddify 应用内是否提供 Free（免费配置）：

  1. 打开 Hiddify 首页，点击顶部 ＋。
  2. 在添加配置面板中查看是否有 Free 开关或免费配置列表。
  3. 如果有，选择其中一个配置，阅读并确认它的使用条款，再按提示添加。
免费配置属于共享资源，可能拥挤、速度较慢或暂时不可用；并非所有版本或地区都一定显示。需要稳定使用时，请使用可信服务提供方给你的配置。本站不会替你提供账号或线路。
怎样连接？怎样确认成功？
  1. 确认首页已经显示 Profile 卡片，点击屏幕中央的连接按钮（Tap to connect）。
  2. 首次连接时，手机按系统提示允许添加 VPN 配置；Android 可能显示连接请求，点击 OK。电脑按系统提示允许 Hiddify 建立 VPN 连接。
  3. 连接成功后，按钮通常会变成绿色并显示 Connected。
  4. 打开浏览器访问常用网页，确认页面能正常加载。再次点击连接按钮即可断开。
注意：显示 Connected 代表隧道已建立，不代表所有网站都一定可访问；还要实际打开网页验证。
Windows / macOS / Android 安装时遇到提示

Windows：下载 EXE 后双击运行。若出现“Windows 已保护你的电脑”，只有在确认文件来自本页指向的 Hiddify 官方 GitHub 发布页后，才可点击“更多信息”查看“仍要运行”；无法确认来源就停止安装。

macOS：打开 DMG，将 Hiddify 拖入 Applications（应用程序）。如果首次打开被 macOS 拦截，先核对下载来源，再按官方 macOS 安装说明处理。不要运行来源不明的“破解 / 修复”命令。

Android：优先使用 Google Play。安装 APK 时，如果系统要求允许“安装未知应用”，只给当前浏览器或文件管理器临时授权；安装完成后可关闭该权限。

iPhone / iPad：通过 App Store 安装。首次连接时按提示点击 Allow（允许），并输入设备密码。

连接失败，先按这个顺序检查

1. 一直显示 Connecting…：先确认当前 Wi-Fi / 蜂窝网络能正常上网；回到配置卡片更新订阅，再尝试切换一个节点。

2. 显示 Connected 但网页打不开：暂时关闭其他 VPN / 代理应用，切换 Wi-Fi 与移动网络测试；仍不行请联系配置提供方。

3. 找不到配置、提示链接无效：联系发给你链接的人确认链接是否完整、有效，以及是否适用于 Hiddify。
