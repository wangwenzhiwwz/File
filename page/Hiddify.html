SUBSCRIPTION

配置链接是什么？

先获得服务提供方给你的链接，Hiddify 才能知道连接到哪里。

01 / GET LINK

获取链接

登录你自己的服务提供方账户，找到订阅、配置或客户端导入入口，复制完整链接。

02 / IMPORT

导入 Hiddify

打开应用，点击添加（＋）或导入配置，选择从剪贴板添加，按提示完成导入。

03 / CONNECT

允许并连接

点击连接按钮。首次使用时，系统会询问是否允许 Hiddify 创建 VPN 配置，确认后即可连接。

Hiddify 是 VPN 服务吗？需要付费吗？

Hiddify 是开源连接客户端，本身不提供线路、账号或流量套餐。你需要使用自己搭建的服务器，或从可信服务提供方获取配置。客户端项目本身免费开源。

下载后为什么不能直接连接？

因为客户端不包含可用线路。你还需要从服务提供方或自己的服务器获取订阅链接 / 配置链接，然后导入应用。

订阅链接和节点链接有什么区别？

订阅链接通常包含多条线路，并可能在服务端更新；单节点链接一般只对应一条线路。具体格式和支持范围以服务提供方说明为准。

导入链接提示无效怎么办？

检查是否复制完整、开头和结尾是否有空格、链接是否过期，以及服务提供方是否支持 Hiddify。不要将链接提交给第三方网站测试。

Windows 提示未知发布者或安全警告怎么办？

先确认下载来源是本页指向的 Hiddify 官方 GitHub Releases，并核对文件名称与版本。无法确认来源时不要继续安装，也不要为了安装而关闭系统安全防护。

macOS 提示无法验证开发者怎么办？

先确认安装包来自官方 GitHub Releases，重新下载最新稳定版并检查系统版本。不要为了安装而关闭 Gatekeeper 或执行来源不明的终端命令。

Android 安装 APK 时提示风险怎么办？

优先从 Google Play 安装。如果所在地区无法使用商店，才从官方 GitHub Releases 获取 APK，并确认文件名及发布版本。不要安装第三方修改版。

iPhone / iPad 搜不到 Hiddify 怎么办？

通过本页 App Store 链接打开应用页面。App Store 的展示和下载可能因 Apple ID 地区而不同；请以 Apple 官方商店页面为准，不要安装来历不明的描述文件。

连接成功但网页打不开怎么办？

先确认订阅没有过期，尝试更新配置并切换其他可用线路；检查设备日期时间是否正确，并暂时排除其他代理或 VPN 应用的冲突。如果只有个别网站无法打开，可能是线路或目标网站本身的问题。

可以把订阅链接发给客服或朋友吗？

除非你完全信任对方且确实需要共享，否则不要发送。订阅链接可能相当于账户凭证，泄露后他人可能使用你的服务。怀疑泄露时联系服务提供方重置订阅。

这个网站会提供免费节点或代配置吗？

不会。本网站只提供客户端官方获取入口、安装说明和基础排查，不销售、不托管、不分发代理节点，也不会要求你提交订阅链接。
