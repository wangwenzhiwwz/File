Hiddify 是客户端，不会自动提供专属线路。连接通常需要服务提供方给你的订阅链接或节点配置。

还没有配置？可在应用内查看是否提供 Free 免费配置；共享线路可能拥挤、限速或暂时不可用。

安装与连接

安装应用 → 添加配置 → 点击连接。通常几分钟即可完成。

1

打开应用

首次打开时，按需选择简体中文和当前所在地区，再点击 Start / 开始进入首页。匿名使用统计可按个人意愿选择。

进入首页后，找到顶部或页面中的「＋」添加按钮。不同系统和版本的界面可能略有差异。
2

添加连接配置

配置由网络服务提供方发放，Hiddify 不会自动生成你的专属线路。

订阅链接通常以 https:// 开头，可包含多条线路，并支持更新。
单节点配置通常以 vless://、vmess:// 等开头，只对应单条线路。
A 已有配置
  1. 点击首页「＋」或「添加配置」。
  2. 复制完整订阅链接后，选择「剪贴板」或「手动」粘贴；订阅链接通常必须以 https:// 开头。
  3. 如果拿到二维码，选择扫码；如果拿到配置文件，选择文件导入。
  4. 也可以打开服务商的用户中心，点击「导入 Hiddify」一键添加。
导入成功：首页出现配置卡片（Profile）。一个配置卡片可能包含多条可切换线路。
B 暂时没有配置

点击「＋」后查看是否有 Free / 免费选项。若有，选择一个免费配置并按提示添加；若没有，则需要向可信服务提供方获取订阅或配置。免费线路由网络提供，可能拥挤、限速或随时不可用。

请勿公开分享配置链接，也不要导入陌生来源的配置。

3

连接并测试

  1. 点击首页的连接按钮。
  2. 首次连接时，系统会询问是否允许 Hiddify 创建 VPN 连接，确认是应用发起后选择允许。
  3. 等待按钮显示 Connected / 已连接，再打开网页测试访问是否正常。
  4. 如有多条线路，通常可先使用 Auto 自动选择；连接失败时更新配置或换一条线路。
各设备安装方法与系统要求

Windows 10（版本 1809）/ Windows 11

  1. 下载 EXE，打开浏览器下载列表并双击安装文件。
  2. 按安装向导完成安装，首次连接 VPN 模式时按系统提示授予权限。
  3. Windows 7 / 8 不受支持。若出现安全提示，先核对文件来自官方发布页。

macOS 10.15 或更新版本

  1. 下载 DMG 并双击打开。
  2. 将 Hiddify 图标拖入「应用程序」文件夹，再从应用程序启动。
  3. 若 macOS 阻止打开，先核对下载来源，再查看官方安装说明，不要运行陌生命令。

Android 7.0 或更新版本

  1. 优先从 Google Play 安装并打开。
  2. 无法使用商店时，可下载通用 APK；打开安装文件，按系统提示完成安装。
  3. 如需允许安装未知应用，只为当前浏览器或文件管理器临时开启，安装后建议关闭。

iOS 15 或更新版本

  1. 在 App Store 点击「获取」，使用 Face ID、Touch ID 或密码确认。
  2. 首次连接时，按提示允许添加 VPN 配置并输入设备密码。
  3. 若商店显示不可用，可能与 Apple ID 所在地区有关。
连接失败与常见问题

提示 Invalid URL / 添加失败：确认链接完整、没有多余空格；订阅链接应为 https://，并确认链接未过期。

一直显示 Connecting：先确认本机网络正常；回到配置卡片点击更新，再尝试 Auto 或切换其他线路。

显示 Connected 但网页打不开：暂时关闭其他 VPN / 代理应用，切换 Wi-Fi 或移动网络后重试。

部分应用无法连接：检查是否启用了 VPN 模式；电脑端若使用系统代理，部分软件可能不会自动走代理。

仍然无法连接：记录错误提示和当前线路，联系配置提供方检查订阅状态及服务器。
