安装完成后，跟着做就能连接

不用懂网络知识。按顺序完成下面 3 步；每一步都告诉你应该看到什么。

1
先做这一步

打开 Hiddify，完成首次设置

安装完成后，在电脑或手机上打开 Hiddify。

  • 如果询问语言，选择简体中文（如果有）。
  • 如果询问地区，选择你当前所在的国家或地区。
  • 如果询问是否发送匿名使用统计，可按个人意愿选择。
  • 进入应用首页后，准备添加配置。
这一步完成的标志：你已经进入 Hiddify 主界面，能看到添加配置的入口（通常是「＋」）。不同版本的按钮位置和文字可能略有不同。
2
选择适合你的方式

添加配置，让 Hiddify 知道要连接哪里

先看你手上有没有服务商发来的订阅链接、二维码或配置文件。

A 我有订阅链接 / 二维码（最常见）
  1. 有一键导入页面：打开服务商发给你的用户中心，点击「导入 Hiddify」或类似按钮；浏览器询问是否打开 Hiddify 时，选择「打开」。
  2. 只有一条链接：先复制完整链接，再打开 Hiddify，点击首页的「＋」或「添加配置」，选择剪贴板导入；如果没有剪贴板选项，就选择手动添加并粘贴链接。
  3. 拿到二维码：在添加配置页面选择扫码 / QR Code，使用相机扫描服务商提供的二维码。
  4. 拿到配置文件：在添加配置页面选择文件导入，再选择对方发给你的文件。
导入成功后：首页会出现一个配置卡片（Profile）。看到配置卡片，就可以进行下一步了。
B 我没有订阅链接，想先试试看
  1. 在 Hiddify 首页点击「＋」或「添加配置」。
  2. 看看页面里是否提供 Free（免费）配置或试用入口。
  3. 如果有，阅读页面说明后按提示添加；如果没有，说明当前版本或地区可能不提供此选项。
免费配置并非每个版本、地区都提供；即使能添加，也可能速度较慢或暂时无法连接。Hiddify 本身不是节点服务商，不会自动赠送稳定线路。需要配置时，请向你信任的服务提供方获取。
安全提醒：订阅链接相当于连接账号凭证。不要把链接、二维码或配置文件公开发到群聊，也不要导入陌生人发来的配置。
3
最后一步

点击连接，确认真的能上网

  1. 回到 Hiddify 首页，确认已经看到刚才添加的配置卡片。
  2. 点击页面中央的连接按钮（可能显示 Connect / 连接 / Tap to connect）。
  3. 第一次连接时，系统可能弹出 VPN 权限提示。确认是 Hiddify 发起后，选择允许 / Allow / OK。
  4. 稍等片刻，应用显示 Connected（已连接）或连接按钮变为已连接状态。
  5. 打开浏览器，访问一个平时能打开的网站，确认网页可以正常加载。
真正成功的标志：Hiddify 显示已连接，而且浏览器能正常打开网页。只看到 Connected 还不够，建议实际打开网页测试。

需要停止连接时，重新打开 Hiddify，点击同一个连接按钮即可断开。

不同设备怎么安装？

Windows 电脑

  1. 点击上方 Windows 下载按钮，下载完成后打开浏览器「下载」列表，双击 .exe 安装文件。
  2. 跟随安装向导操作，通常保持默认选项即可。
  3. 如果出现安全警告，先确认文件来自本页链接的 Hiddify 官方 GitHub 发布页；无法确认来源时不要继续安装。

Mac 电脑

  1. 下载 DMG 文件，在「下载」文件夹中双击打开。
  2. 将 Hiddify 图标拖到「应用程序」文件夹。
  3. 从「应用程序」中打开 Hiddify。若系统阻止打开，请先核对下载来源，再查看官方安装说明，不要运行陌生人提供的修复命令。

Android 手机

  1. 优先从 Google Play 安装，点击「安装」后等待完成。
  2. 如果使用 APK，下载后点击文件并按系统提示安装。只在确认 APK 来自官方发布页后安装。
  3. 如果系统要求允许安装未知应用，只为当前浏览器或文件管理器临时开启；安装完成后建议关闭。

iPhone / iPad

  1. 点击 App Store，选择「获取」，按提示使用 Face ID、Touch ID 或密码确认。
  2. 安装完成后点击「打开」。如果商店显示不可用，可能与 Apple ID 所在地区有关。
我卡住了：常见问题怎么处理？

找不到「＋」或添加配置入口：回到应用首页，查看顶部或页面中的添加按钮；不同版本界面可能不同，也可以参考官方使用教程。

提示链接无效 / Invalid URL：确认复制的是完整链接，没有漏掉开头或结尾；再向配置提供方确认链接是否过期、是否适用于 Hiddify。

一直显示 Connecting：先确认手机或电脑本身可以正常上网，再尝试更新配置；仍无法连接时联系配置提供方。

显示 Connected，但网页打不开：暂时关闭其他 VPN 或代理应用，切换 Wi-Fi / 移动网络再测试；仍不行请联系配置提供方。

系统询问是否允许 VPN：这是建立本机 VPN 连接所需的系统授权。确认请求来自 Hiddify 后再允许；不确定时先取消并核实。
