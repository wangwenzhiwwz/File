从安装到成功连接

按顺序完成下面几步，不需要了解技术术语。

① 如何安装？按你的设备查看

Windows 10 / 11（64 位）

  1. 下载 Windows 安装包（.exe），在浏览器下载记录或“下载”文件夹中双击打开。
  2. 按安装程序提示继续，保持默认选项，完成后点击 Finish。
  3. 如果出现“Windows 已保护你的电脑”，先确认文件来自本页的 Hiddify 官方 GitHub 下载，再点“更多信息”查看发布者信息；无法确认来源时不要继续安装。

macOS 10.15 或更新版本

  1. 下载 DMG，打开下载的文件。
  2. 将 Hiddify 图标拖到 Applications（应用程序）文件夹。
  3. 从“应用程序”中打开 Hiddify。若 macOS 提示无法验证应用，请先查看官方 macOS 安装说明，不要随意下载所谓修复工具。

Android 7.0 或更新版本

  1. 优先点击 Google Play 安装并打开。
  2. 如无法使用 Google Play，再下载本页 APK，打开下载文件并按系统提示安装。
  3. 若系统要求允许“安装未知应用”，只对本次使用的浏览器或文件管理器临时授权；安装后可关闭该权限。

iPhone / iPad（iOS 15 或更新版本）

  1. 点击 App Store，点“获取”并完成验证。
  2. 安装后打开 Hiddify。首次连接时，按系统提示允许添加 VPN 配置并输入设备密码。
② 没有配置链接？先了解这一点

下载 Hiddify 不等于已经拥有可用线路。Hiddify 是连接工具，本身不提供个人专属服务器或订阅服务。

你需要向自己信任的服务提供方获取订阅链接 / 用户链接，或由对方提供二维码、配置文件。不要使用陌生人发来的不明链接。

订阅链接通常以 https:// 开头。它可能包含你的账号权限，请勿发到公开群聊或社交平台。

③ 怎样导入订阅链接？
  1. 先复制服务提供方给你的完整订阅链接。若对方提供的是个人用户页面，打开页面并点击“在 Hiddify 中打开”一类按钮，通常可以直接导入。
  2. 如果不能自动打开 Hiddify：进入 Hiddify 首页，点击顶部的 ＋。
  3. 选择 Clipboard（剪贴板） 导入刚才复制的链接。也可以选择二维码扫描，或进入 Manually（手动）粘贴链接后添加。
  4. 添加成功后，首页会出现一个配置 / Profile 卡片。
看到 Invalid URL 或添加失败？检查是否复制了完整链接、开头是否为 https://，并确认链接没有过期；仍失败请联系链接提供方。
④ 怎样开始连接？
  1. 在 Hiddify 首页确认已经出现配置卡片。
  2. 点击页面中央的连接按钮（Tap to connect）。
  3. 首次连接时，手机按提示点“允许 / OK”；电脑按系统提示允许 Hiddify 创建 VPN 连接。
  4. 按钮显示绿色 Connected（已连接）时，表示连接已建立。再次点击可断开。
完成标志：Hiddify 显示 Connected，打开浏览器访问一个网页确认网络正常。若显示已连接但网页无法打开，尝试切换网络或联系服务提供方。

常见问题

一直显示 Connecting…：回到首页更新配置，或在 Proxies（节点）中换一个线路再试；仍不行请联系服务提供方。

显示 Connected 但无法上网：检查当前 Wi-Fi / 蜂窝网络是否正常，暂时关闭其他 VPN 或代理应用后再试。

不知道去哪里找订阅链接：联系提供你服务的商家或管理员。本站不出售订阅，也无法替你生成个人配置。
